## Review: test quality

**Bottom line: the app contains zero tests and no working test infrastructure.** `grep` for `describe(`/`it(`/`expect(` across `app/src` returns nothing, `app/angular.json` has no `test` target, and there is no `vitest`/`jsdom` in `app/package.json` devDependencies — yet `package.json:10` declares `"test": "ng test"`, which would fail outright. In Angular 22 (the app's own `@angular/cli` version, `^22.2.5`), Vitest is the stable default runner wired in by the CLI for new projects; adding it plus a handful of pure-function tests for `helpers.ts` was cheap and was skipped.

What makes this worse is that this app is *dense* with exactly the kind of logic the review brief flags: pure data transformation in `app/src/app/core/helpers.ts` (humanize, `latestEnglishFlavor` with whitespace/`\f` collapsing at :41–49, `dexNumber` zero-padding at :51, `formatDecimal` ÷10 at :59), filtering + pagination + URL-state in the home-page loader (`app/src/app/pages/home-page.ts:153–167`: set-membership filters, `Math.ceil`/`Math.min` page clamping), URL round-tripping through `buildQuery`/`updateFilters` (`home-page.ts:238–243`, which silently drops empty params and resets `page` on filter change), a comparator with deliberate null-handling in `app/src/shared/move-table.ts:130–145`, and move-table grouping with a custom method ordering in `app/src/app/pages/pokemon-page.ts:296–326`. None of it is pinned by a single assertion; once the acceptance suite stops being the guard, any refactor of `PokedexData`/`PokeApi` can silently reorder, drop, or mis-render data with nothing failing.

Two latent bugs a first test run would likely have surfaced: (1) `app/src/app/core/poke-api.ts:15–21` caches the *Promise*, so a rejected request is cached forever — one transient failure permanently breaks that resource until reload; (2) `idFromUrl` (`helpers.ts:18–20`) returns `NaN` for malformed URLs and `isAlternateForm` uses `> 10000` while `getAllTypes` uses `<= 10_000` as the cut — boundary conventions that nothing verifies agree.
