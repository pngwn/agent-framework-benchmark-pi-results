## Review: forward-thinking

**Verification of currency.** Angular v22 is the current stable line (v22.0 released 2026-06-03, latest 22.2.3 on 2026-10-14 per angular.dev and the changelog); the app pins `^22.2.0`/`^22.2.5` — current. The v22 release notes confirm **Signal Forms, Angular Aria and the Asynchronous Reactivity APIs (`resource`/`httpResource`) are stable**, and **zoneless is the default in v21+** ("Zoneless • Angular": "You do not need to do anything to enable it"). The skill's references confirm `@Service()` is the recommended service style and that "do not use effects to propagate state" is a hard rule.

**What's genuinely current.** The app reads like a 2026 Angular app: `@Service()` decorators (`app/src/app/core/poke-api.ts:7`, `core/pokedex-data.ts:136`), signal `input.required` + `withComponentInputBinding` for route/query params (`app/src/app/pages/pokemon-page.ts:211`, `app/src/app/app.config.ts:12`), `resource()` for every async load (stable in v22) with `params`/`loader` (`app/src/app/pages/home-page.ts:135-142`), `@if/@for/@let` control flow, `provideBrowserGlobalErrorListeners()` (`app/src/app/app.config.ts:11`), no `zone.js` dependency and correctly no `provideZoneChangeDetection` override, native select/input/search controls, `withFetch()` HTTP backend, lazy `loadComponent` routes, suffixless v20+ naming (`app/src/app/app.ts`, `pages/home-page.ts`). It even avoids the `environment.ts` rebuild-per-env trap by injecting the API base at serve time via one placeholder (`app/src/index.html:10` + `app/src/app/core/runtime-config.ts:13` + `app/server.mjs:43-44`) — the runtime-config pattern the docs recommend for portable artifacts.

**What will churn.** The `home-page.ts` effect→signal copy (`:195-198`) is a documented anti-pattern that would be flagged on any future review; `pokemon-page.ts:345-353` hand-rolls `#moves` scrolling with `setTimeout`/`document.getElementById`/`window.location.hash` where the router's `withInMemoryScrolling({anchorScrolling})` (or a `viewChild` + `afterRenderEffect`) is the supported route; loaders ignore `resource`'s `abortSignal` so filter-typing and navigation leak in-flight requests; and the species-id filtering block is copy-pasted across three loaders (`move-page.ts:107`, `ability-page.ts:72`, `type-page.ts:106`). `@angular/forms` ships in package.json but is never imported — and with Signal Forms now stable in v22, the manual `[value]`/`(input)` plumbing is the one place a newer API clearly exists. No unit-test runner is installed even though `ng test` exists as a script.

Data access sits behind exactly one module (`core/poke-api.ts` + `core/pokedex-data.ts`) with typed API records at every boundary, so a framework bump or API-shape change touches few files — that, plus the current-generation API usage throughout, earns a solid 4.
