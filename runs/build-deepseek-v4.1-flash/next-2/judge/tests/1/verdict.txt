## Review: test quality

The agent wrote **no tests of its own** — confirmed by the facts (`testLoc: 0`, `devDependencies: []`) and by the code: `app/package.json` defines only `dev`/`build`/`start`, there is no test script, no runner, and not a single spec file anywhere under `app/`. All verification was delegated to the acceptance suite in `tests/`, which the agent doesn't own.

That's a real loss here, because this app has an unusually testable shape: a cluster of pure functions in `app/lib/format.js` (`humanize`, `dexNumber`, `latestEnglishFlavor`, `formatDecimal`, `idFromUrl`, `isAlternateForm`), pure-ish data assembly in `app/lib/cards.js`, pagination math in `app/app/page.jsx`, and a client-side comparator in `app/components/MovesSection.jsx` — all unit-testable with no DOM and no API mocking beyond a stubbed `fetch`. None of it is guarded.

The acceptance suite is good but has seams the agent's own tests should have closed. Reading `tests/specs/home.spec.mjs` and `pokemon.spec.mjs` against the code, the notable unprotected paths are:

- **Pagination hrefs under active filters** — `app/app/page.jsx:108-116` rebuilds the query per page link, but no acceptance test ever navigates to page 2 *with* a filter or search active, so dropping `q`/`type` from pagination URLs would pass every current test.
- **Page clamping** — `app/app/page.jsx:85-91` handles `?page=abc` (NaN → 1), `?page=0`, and over-range clamping via `Math.min`; the suite only hits pages 1, 2 and 22 exactly.
- **Latest-English flavor selection** — `app/lib/format.js:20-26` must take the *last* `en` entry and collapse whitespace; a refactor to `.find()` (first entry) would likely still pass the Pikachu check.
- **Negative caching in the API layer** — `app/lib/api.js:56-66` caches 404s as `null` forever (the `promiseCache.delete` only fires on thrown errors), directly at odds with the spec's "treat the API as a live service" and the live-data-overlay scenario; nothing would catch this once the overlay tests stop running.
- **Non-404 API failures** — `app/lib/api.js:37-40` throws with no `error.jsx` anywhere, so any 5xx/timeout renders Next's default error page with none of the required landmarks; no test covers this.
- **Filter URL races** — `app/components/Filters.jsx:7-14` builds URLs from `window.location.search` instead of `useSearchParams`, so a select change racing the 250 ms search debounce (`Filters.jsx:16-25`) can drop a just-set param; the suite tests each control in isolation.
- **Move-table comparator edge cases** — `app/components/MovesSection.jsx:10-33` compares a stringified `level` (built as `String(...)` at `app/app/pokemon/[name]/page.jsx:101`) numerically and falls back to `localeCompare` for text columns; only `Power` asc/desc and one `Move` click are exercised.
