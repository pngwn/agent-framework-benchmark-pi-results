## Review: test quality

**The agent wrote no tests at all.** `app/package.json` has no `test` script, an empty `devDependencies` block, and no runner (vitest/playwright) is installed anywhere in `app/` — the measured facts confirm 0 test files. All protection comes from the black-box acceptance suite in `tests/`, which exercises only a handful of happy paths on a handful of species. Yet the app contains a large amount of pure, easily-testable logic (a `lib/format.ts` full of spec-driven string/number rules, a 700-line data layer in `lib/queries.ts`, sorting and pagination in components/routes) that currently has zero safety net for refactors.

Where the risk concentrates:

- **Sorting**: `app/src/components/MoveTable.tsx:11` — `sortRows` implements the spec's trickiest rule (missing values sort last in *both* directions, handled by returning before the direction multiplier) plus `aria-sort` bookkeeping at `MoveTable.tsx:53`. A refactor that applies the direction to the missing-value comparison would pass every acceptance test unless a fixture happens to have a null in the sorted column.
- **Pagination**: `app/src/routes/index.tsx:96-104` — clamping (`?page=99` → last page, `?page=0` → 1), `totalPages`, and the `slice` are classic off-by-one territory; acceptance only walks Previous/Next on pages 1–2.
- **Level-up dedupe**: `app/src/lib/queries.ts:566-576` — collapsing multiple `version_group_details` for the same move into the minimum level is subtle, and other methods rely on "first entry wins" (`queries.ts:572`).
- **URL-state sync**: `app/src/routes/index.tsx:29-77` — a hand-rolled debounce plus a `createEffect` reconciling the input with the URL through a mutable `lastUrlSearch` closure (`index.tsx:41-43`); back/forward navigation races here are exactly what an interaction test would catch.
- **Error paths**: `app/src/lib/queries.ts:159-166` — `fetchJson` throws on any non-404 failure, and `app/src/app.tsx:19` has a `Suspense` with no `ErrorBoundary`; a 500 from the API leaves a blank page. Nothing tests this.
- **Alternate-form exclusion**: the magic `id > 10000` guard is copy-pasted in four places (`queries.ts:292`, `367`, `416`, `453`); changing one and not the others leaks Mega Evolutions into exactly one list type.
- **Formatters**: `app/src/lib/format.ts:20-28` — `collapseWhitespace` (spec demands `\n`/`\f` runs collapse), `formatMeasurement` (decimetres → `0.4 m`), `dexNumber` padding. One-line unit tests each; none exist.

The pure functions in `lib/format.ts` and the transformation logic in `lib/queries.ts`/`MoveTable.tsx` would be trivial to cover with vitest (no DOM needed) — the agent's choice to ship zero is the main weakness of this PR.
