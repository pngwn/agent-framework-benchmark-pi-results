## Review: experimentalness

**Toolchain.** The only new-ish elements live in `app/package.json:12-13` — `typescript@^7.0.2` and `vite@^8.3.5`. I verified both against release notes: TypeScript 7.0 (the Go-native compiler rewrite) went GA on 2026-07-08 (devblogs.microsoft.com/typescript/announcing-typescript-7-0/), and Vite 8.0 (Rolldown bundler) has been stable since 2026-03-12 (vite.dev/blog/announcing-vite8). Neither is experimental today, but TS 7 is a ~4-month-old wholesale compiler rewrite. The config files are plain: `app/tsconfig.json:1-18` has no `experimental*` flags, and `app/vite.config.ts:1-6` sets nothing preview-gated.

**Runtime code.** The app's actual code reaches for nothing new. Spot-checking every web API used:
- `fetch` with a promise cache — `app/src/api.ts:158-167` (Baseline for years)
- `history.pushState/replaceState` + `popstate` client-side routing — `app/src/main.ts:82-91`, `app/src/pages/home.ts:121-135`
- `URLSearchParams`, `URL`, `decodeURIComponent` — `app/src/pages/home.ts:14`, `app/src/main.ts:18`
- `String.replaceAll` / `padStart` — `app/src/components.ts:4-8`, `app/src/api.ts:190` (ES2021, matches `target: ES2022` in tsconfig)
- `loading="lazy"` img attribute — `app/src/components.ts:49`
- CSS uses only `@import`, `@media` queries and `aspect-ratio` — `app/src/style.css:1, 609, 640, 673`; no nesting, `:has()`, `color-mix()`, container queries or `@layer`
- No `experimental`/`unstable`/`preview` names anywhere in source (only matches were `NamedAPIResource` types and lockfile URLs)

The only genuinely current-generation choices are the toolchain majors, both of which are the *current stable* releases — which is exactly what a PR should target, not a reach. Risk is low: the config surface (standard strict tsconfig, a two-line vite config) would survive a toolchain downgrade unchanged.
