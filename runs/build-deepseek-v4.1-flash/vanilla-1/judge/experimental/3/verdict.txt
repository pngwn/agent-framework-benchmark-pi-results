I've reviewed the app end to end and verified the status of the only "new" things present (the toolchain majors) against their release announcements.

**What I found in the code**

- Runtime code (`app/src/main.ts:59-86`, `app/src/pages/home.ts:130-149`, `app/src/api.ts:154-169`) uses only long-stable web-platform APIs: `history.pushState`/`replaceState`, `URL`/`URLSearchParams`, `fetch`, `requestAnimationFrame`, `scrollIntoView`, `loading="lazy"` images (`app/src/components.ts:47`). Nothing experimental, no `unstable_`/`experimental_` names, no canary flags — matches the measured facts (`experimental: []`, `concepts.ambient: ["meta"]` only).
- `String.replaceAll` (`app/src/components.ts:5-9`) is ES2021, several years stable; tsconfig targets ES2022 (`app/tsconfig.json:3`).
- `vite.config.ts` is a 4-line config with no experimental flags; it explicitly pins a conservative `build.target: 'chrome120'` (`app/vite.config.ts:4`) rather than relying on Vite 8's new `baseline-widely-available` default.
- The production server (`app/server.mjs`) uses only `node:http`/`node:fs`/`node:path`/`node:url` — the stable Node core surface.

**Toolchain status (verified)**

- TypeScript `^7.0.2` (`app/package.json:14`): TS 7.0, the native Go-port compiler, was announced stable on **2026-07-08** (devblogs.microsoft.com "Announcing TypeScript 7.0"; 7.0.2 tag 2026-08-20). ~3 months old — a *very* recent major, but stable, and the app only uses it for CLI type-checking (`noEmit`, `app/tsconfig.json:13`), never the (removed) programmatic compiler API.
- Vite `^8.3.5` (`app/package.json:15`): Vite 8.0 (Rolldown-based) went stable on **2026-03-12** (vite.dev/blog/announcing-vite8). ~7 months old. Note: Vite 8.0.0 shipped with `rolldown 1.0.0-rc.9` internally (Vite changelog), but that's an implementation detail of the stable release and the app passes no Rolldown options.

So this is a deliberately conservative codebase from an experimentalness standpoint: zero experimental/preview/RC APIs in the app code, with two *recently-stable* toolchain majors (which are simply the current stable releases, and the correct ones to pick).
