## Key findings driving the scores

- **Latent bug in the error path**: `app/src/lib/api.ts:22` throws using `res.status`/`res.statusText` — `res` doesn't exist (it's `response`); the purpose-built `ApiError` (`:4`) is never thrown. Every non-OK response becomes a swallowed `ReferenceError`, losing the status code and making API failures misleading to debug.
- **Duplicated alternate-form exclusion**: `app/src/routes/(home).ts:60-62` re-implements ID extraction and the `< 10000` rule inline instead of using `idFromUrl`/`isSpeciesId` (`app/src/lib/api.ts:38-45`) used everywhere else in `data.ts`.
- **Dead + duplicated helpers**: `notFound`/`sectionHeading` (`app/src/lib/components.ts:43-51`) are exported and never used, while identical Not-found markup is inlined in `404.ts:8-13`, `pokemon/[name].ts:54-59`, `moves/[name].ts:30-36`, `abilities/[name].ts:33-39`, `types/[name].ts:29-35`. `getAbility` (`data.ts:139`) is dead.
- **Pervasive `any`**: `api<T = any>` (`api.ts:17`), `(entry: any)` casts throughout `data.ts` and templates — refactors get no compiler support.
