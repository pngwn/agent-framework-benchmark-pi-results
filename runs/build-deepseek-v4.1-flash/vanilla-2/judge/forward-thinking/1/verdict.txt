## Review

**What this is:** A zero-runtime-dependency vanilla JS SPA on Vite 8, with a hand-rolled ~110-line Node static server for production, a client-side router built on the History API, string-template rendering, and a two-module data layer.

**Currency check (verified, not from memory):**
- Vite's current stable is **8.3.5** (npm `latest` tag, published 2026-10; vite.dev/releases shows `vite@8.3` receiving regular patches). The app pins `^8.3.5` (`app/package.json:14`) and uses **zero config** — no `vite.config` file at all, so there is nothing to migrate when Vite 9 lands, and no deprecated options like the v8-removed `optimizeDeps.esbuildOptions`.
- The **Navigation API** reached Baseline 2026 "Newly available" (MDN, updated 2026-01-14; web.dev "Modern client-side routing", 2026-02-17) and is the current-generation platform replacement for exactly the hand-rolled `pushState`/`popstate`/click-interception pattern this app uses. For a spec that targets only latest Chromium, that's the modern choice; the History API used instead is still fully supported (not deprecated).
- Everything else — `fetch`, `URL`/`URLSearchParams`, ES modules, `String.replaceAll`, `node:`-prefixed builtins, custom properties, grid, `aspect-ratio` — is current.
