## Review

This is a SvelteKit 3 app (the current stable release, October 2026), and it is *consciously* written against that release's conventions rather than SvelteKit 2 muscle memory: configuration lives in the Vite plugin (`app/vite.config.js:5`), the `#lib` subpath-import alias is declared in `package.json exactly as the v3 migration guide prescribes (`app/package.json:14`), runes/`$props`/`{#snippet}` are used throughout with zero legacy `export let`/`$:`/`$page`, and the home page uses the brand-new `goto(..., { shallow: true, replace })` API — the replacement for the now-deprecated `pushState`/`replaceState` — to keep filter state in the URL without re-running `load` (`app/src/routes/+page.svelte:53`). `error(404, 'Not found')` in its new string-message form is called without `throw`, which is correct (`app/src/routes/pokemon/[name]/+page.server.js:36`).

The one place where it slips off the current API is a real one: SvelteKit 3 **removed** the `noScroll`/`keepFocus` `goto` options in favour of `reset: false` (PR #16558, merged 2026-07-29; there is even an official error page `svelte.dev/e/kit/goto_options_removed` for it). `app/src/routes/pokemon/[name]/+page.svelte:16` still passes them, so they are silently ignored and changing the `Game` select resets scroll/focus — visible exactly on the spec's `#moves` screenshot scenario.

Smaller items: `+error.svelte` hard-codes "Not found" for every error status, so an API outage renders as a 404 page; the move-table row key `moveName + ':' + level` can collide on duplicate (move, level) pairs; helpers are duplicated (`isMissing` ×3 with divergent semantics, flavor-text collapsing ×3 while the exported `latestEnglishFlavorText` sits unused) and `getPokemonCard` is dead code; and the styles for `PokemonCard`/`MoveTable`/`TypeBadge` markup all live in the global `app.css` (`app/src/app.css:154`, `:238`, `:319`), so component markup and its CSS live in different files.

Server-side data loading is well done: a single cohesive server-only module with a promise-level memo cache that evicts failed requests (`app/src/lib/server/pokeapi.js:8`), 404-aware fetching (`:20`), and shape-derived views per route. No `{@html}`, no leaked listeners, no SSR/CSR mismatch paths.
