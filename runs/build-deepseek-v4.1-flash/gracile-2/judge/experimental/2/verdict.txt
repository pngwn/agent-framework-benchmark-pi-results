I've reviewed the app's framework usage against Gracile's current stable release and docs. Summary of what I verified:

- `@gracile/gracile` **0.11.0 is the latest stable** on npm (published ~6 months ago; `0.11.1-next.*` prereleases exist, which the app correctly does **not** use). The app pins it **exactly** (`app/package.json:5`, no caret) — the right move for a pre-1.0 framework.
- Every API used is the framework's documented core, not an experimental surface: `defineRoute` (`app/src/routes/(home).js:1` and 7 other routes), `html` from `@gracile/gracile/server-html` (`app/src/document.js:1`), the `gracile` Vite plugin with `output: 'server'` (`app/vite.config.js:5`), and the Express adapter (`app/server.js:11,19`). `app/server.js:4-20` is nearly verbatim the documented Express setup from gracile.js.org's output-modes page (`getClientBuildPath` + `nodeAdapter`).
- The **one feature Gracile explicitly labels experimental — the CSR add-on** ("For now, the Gracile CSR add-on is under an experimental phase", gracile.js.org/docs/learn/usage/output-modes/) — is **deliberately not used**: client interactivity is plain vanilla DOM scripting in per-route `.client.js` sidecars (`app/src/routes/(home).client.js`, `app/src/routes/pokemon/[name].client.js`), a stable Gracile convention. No hydration, no Lit custom elements, no `staticPaths`/prerender, no add-ons.
- Companion deps are all current stable lines: Vite 8.x (stable; Gracile's own add-ons peer-depend on `vite ^7 || ^8`), Express 5.3, Lit 3.3.
- No `unstable_*`/`experimental_*` names, flags, or canary builds anywhere (measured `experimental: []` matches my grep of `app/`).
- Caveat: Gracile's own docs state "This project is in an **alpha** state" — so the whole foundation is pre-1.0 by design; that's a spec mandate, not the author's choice, and the app minimizes exposure to its churnier parts.
- Minor notes: `trailingSlash: 'ignore'` (`app/vite.config.js:6`) I could not confirm in the current docs (low risk, build succeeded); `res.locals.requestId` (`app/server.js:12-14`) is copied from the docs' example but never consumed by any route.
