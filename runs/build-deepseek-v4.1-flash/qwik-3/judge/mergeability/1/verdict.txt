## Review

**Structure & framework use.** This is a recognisably modern, current-stable Qwik City app (`@builder.io/qwik@^1.20.3`, matching the actual latest stable, 1.20.3, Oct 2026; Qwik 2.0 is still rc). Data loading uses `routeLoader$` with server-only `lib/api.ts`, `DocumentHead` uses the documented `resolveValue` pattern (`app/src/routes/pokemon/[name]/index.tsx:96`), a `[...slug]` catch-all handles 404, and the official node-server adapter serves the build. Client interactivity (move-table sorting) uses `useSignal` handlers — idiomatic. The server/client boundary is respected: components only pull types from `~/lib/api` via `import type` (`app/src/components/MoveTables.tsx:3`, `app/src/components/ui.tsx:2`).

**The main wart is home-page URL state.** `app/src/routes/index.tsx` bypasses Qwik City's router entirely: raw `history.replaceState`/`pushState` (lines 69, 86, 108, 141, 158) plus its own `popstate` listener (lines 35–41), while Qwik's SPA router *also* handles popstate and re-runs loaders. It works, but two navigation models coexist in the codebase (the Pokémon page's `Game` select uses `useNavigate` at `pokemon/[name]/index.tsx:118`), and back/forward on the home page means the router and the app's listener both fire. Deriving signals from `useLocation().url` in a `useTask$`/`useComputed$` and updating via `navigate()` would be cleaner and router-consistent.

**Abstractions.** `lib/api.ts` is a ~450-line god data module every route imports — types, the cache, formatting helpers, and five page loaders. Locally fine, but it's the file every future feature touches. `components/ui.tsx` is a junk drawer: `HomeCards` and `PokemonCards` are near-duplicates, and `typeClassName` (line 52) is dead code that duplicates the `type-${name}` pattern inlined in four other places.

**Correctness.** Careful work overall: 404-aware loader with `status(404)`, cache entries evicted on failure (`api.ts:81-85`), invalid `?game=` values rejected (`api.ts:359-361`), alternate forms filtered at `id > 10000` throughout, missing values rendered as em dashes. Risks are minor: unbounded `Promise.all` fan-out for move details (`api.ts:391` — a TM-machine-heavy Pokémon in scarlet-violet fires 150–200 concurrent fetches on first load), 404 responses cached as `null` forever (`api.ts:75`), and no fetch timeout. Nothing I'd block on.
