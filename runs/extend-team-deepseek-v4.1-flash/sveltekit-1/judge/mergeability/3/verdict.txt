## Review: SvelteKit Pokédex app

**Framework currency check (verified, not from memory):** SvelteKit 3 is the current stable and this app matches its conventions exactly — config lives in `vite.config.ts` via the `sveltekit()` plugin (`app/vite.config.ts:1-15`, no `svelte.config.js`), `#lib/*` subpath imports are the current scaffolding default (`app/package.json:25-27`), the function-form `runes: ({filename}) => …` compiler option is a supported 2026 feature mirroring the official scaffold, `error()` is the throwing Kit-2/3 API, and `PageProps`/`LayoutProps` generated types are used everywhere. Every component is clean runes-mode Svelte 5: `$props`, `$derived`, `$derived.by`, snippets/`{@render}`, `onclick=`, self-import recursion instead of `svelte:self` (`app/src/lib/components/Evolution.svelte:5`), `style:` custom properties for dynamic type colors. Server-only data code is correctly quarantined under `lib/server/` and only imported from `+page.server.ts` files.

**What holds up well:** data loading is exactly the recommended shape — server `load` functions, a thin cached HTTP client (`app/src/lib/server/api.ts`), 404 → `error(404)` on every entity route, pagination/filter state in the URL, `afterNavigate`-guarded search input with an explicit comment about stale-keystroke races (`app/src/routes/+page.svelte:17-19`). The team feature integrates cleanly: cookie as shared source of truth parsed/serialized in one module (`app/src/lib/team.ts`), server render from the cookie so the button never flashes the wrong label.

**What I'd ask to change:** the copy-of-load-data-into-`$state`-plus-`$effect`-resync pattern appears twice (`app/src/routes/pokemon/[name]/+page.svelte:24`, `app/src/routes/team/+page.svelte:13`) — the official skill explicitly says avoid updating state in effects; updating the cookie and `invalidate()` would keep `data` the single source of truth. The search debounce timer is never cleared on unmount, so a keystroke followed by a quick card click can yank the user back to the search page 200ms later. `pokedex.ts` is a 470-line single module holding API shapes plus all six pages' loaders — coherent today, but it's the one file that will need splitting first.
