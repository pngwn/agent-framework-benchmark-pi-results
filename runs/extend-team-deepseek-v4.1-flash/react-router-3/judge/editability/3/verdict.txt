## Review summary

This is a well-organized, small-but-real React Router 8.5 framework-mode app. Server-only code lives in `.server` modules imported only from loaders/actions (`app/app/lib/api.server.ts`, `app/app/lib/team.server.ts`), the shared constant (`MAX_TEAM_SIZE`) is split into a browser-safe module (`app/app/lib/team.ts`), and every Pokémon card list funnels through one helper (`speciesCard`/`pokemonCards` in `app/app/lib/api.server.ts:137,154`) and one component (`app/app/components/PokemonCards.tsx`). That makes the highest-risk scenarios — a sprite fix and a data-source change — single-file edits.

The main deductions are duplicated spec-level rules and a small leak of one feature into a shared abstraction: the "Hidden ability" annotation is baked into the generic `Card` type and card component, and the Effect-fallback rule ("short_effect, else latest flavor text, else —") is written twice, as is the `Move` API record type. The home page's ref-plus-`useEffect` filter plumbing works but is the subtlest code in the repo and would be the least fun place to add a fourth filter. The team feature (the later change) is a model change: two new isolated modules, a render-prop extension (`itemExtra`) to the card list instead of a copy or a flag, and a ~5-line touch to the Pokémon route.
