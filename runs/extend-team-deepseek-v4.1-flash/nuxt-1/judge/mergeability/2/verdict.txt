Here's my review.

## Review notes

**Strengths**
- The Nuxt 4 conventions are used correctly and fully: `app/` srcDir layout, `server/api` Nitro routes, auto-imported composables/components, `error.vue`, `useHead`/`useFetch`/`useAsyncData`/`useCookie`/`useRuntimeConfig`, and the `NUXT_PUBLIC_API_BASE` → `runtimeConfig.public.apiBase` override in `app/package.json:7`.
- 404 handling is thorough: upstream 404s map to a `NotFound` error (`app/server/utils/pokeapi.ts:19`), `withNotFound` turns that into a Nitro 404 (`app/server/utils/pokeapi.ts:62`), pages throw `fatal` errors via `usePageData` (`app/app/composables/format.ts:36`), and a catch-all page covers unknown URLs (`app/app/pages/[...slug].vue:2`).
- The feature change is well-integrated: cookie-backed team state (SSR-correct, no flash, per `FEATURE.md`), reusing `PokemonCard`, `PageSection` and the server `api()` cache; `shownMembers` (`app/app/pages/team.vue:18`) guards against stale refetch data, and `server/api/team.get.ts:33` tolerates species that disappear from the API.
- Nice attention to edge cases: failed fetches aren't cached (`app/server/utils/pokeapi.ts:39`), search typed before hydration is picked up (`app/app/pages/index.vue:87`), missing values sort last in both sort directions (`app/app/components/MovesTable.vue:49`), duplicate move/level rows kept (`app/app/pages/pokemon/[name].vue:74`).

**Issues**
- The Pokémon endpoint fans out one upstream request per learned move (~100–200) with no concurrency cap (`app/server/api/pokemon/[name].get.ts:37`), and one failed fetch fails the whole page via `Promise.all`. Fine against a local snapshot API, fragile against anything slower.
- `humanize` is implemented twice (`app/app/composables/format.ts:1`, `app/server/utils/pokeapi.ts:34`) — Nuxt 4's `shared/` folder exists exactly for this; same for the inline sprite-URL construction in `app/app/pages/index.vue:33` vs `spriteUrl` in `app/server/utils/pokeapi.ts:57`.
- `usePageData`/`usePageTitle` live in a file named `format.ts` (`app/app/composables/format.ts:23`), which is the only real misorganization.
- All styles live in one 520-line global `main.css` instead of scoped SFC styles — organized, but component styles sit far from components and class names are global.
