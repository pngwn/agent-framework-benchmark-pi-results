## Review summary

The app is built on SolidStart **v2** (stable since Aug 2026: Vite 8 + Nitro v3, `vite.config.ts` instead of `app.config.ts`), and it matches the current docs almost line-for-line — `query` + `"use server"` + `createAsync` for data, `route.preload` exports, `@solidjs/start/http` for cookies, `FileRoutes`, `HttpStatusCode` for 404s, `createHandler({ mode: "async" })` in the entry server. Layering is clean: a thin RPC boundary (`queries.ts`), one server data module, shared contracts in `types.ts`, presentational components, and a small, pure team-cookie store. The main gap is that the framework's own docs tell you to wrap data loading in an `ErrorBoundary` and the app has none, so any non-404 API failure surfaces as an unhandled render error.
