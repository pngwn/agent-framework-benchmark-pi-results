## Review summary

This app rides the **current stable stack**: React Router `^8.5.1` (v8 shipped June 2026; 8.5.1 is the latest), React 19.3, Vite 7, TS 5.9. It follows v8-era guidance well — `Layout` export in `app/app/root.tsx:7`, `data()` from `react-router`, route props instead of hooks, and React 19 `<title>` hoisting in components, which the v8 route-module docs explicitly recommend over the `meta` export ("Since React 19, using the built-in `<title>` element is recommended"). All data access is centralized in one `.server` module, so framework or API changes are contained.

The notable weaknesses are forward-looking: the framework generates route types (`.react-router/types` is even wired into `app/tsconfig.json:3-10` and the typegen script exists in `app/package.json`), but no route imports `./+types/*` — five route components take `loaderData: any` and loaders hand-roll arg types. And the home loader ships the entire 1,025-species catalog on every query-param change (each debounced keystroke triggers loader revalidation) when `shouldRevalidate` exists precisely to opt out.
