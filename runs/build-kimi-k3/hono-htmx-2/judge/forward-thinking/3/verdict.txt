I've reviewed the app against current framework releases. Key verification results:

- **hono**: app pins `^4.13.14` — that is the latest stable (v4.13.14, 25 Oct 2026; v5.0.0-rc.1 exists but is a prerelease). All core APIs used (`Hono`, `app.get`, `c.html`, `c.req.query`, `app.notFound`, `app.onError`, `html` from `hono/html`) match the current docs/skill reference.
- **@hono/node-server**: app pins `^1.19.0`, but current is **2.1.5** (v2 released Apr 2026). The 1.x line's last release was Jul 2026 and did **not** receive the Sep 2026 `serveStatic` path-decoding security fix (GHSA-rmxm-3fg6-px4f, fixed in 2.1.3) — and the app serves static files through exactly that subpath (`@hono/node-server/serve-static`).
- **htmx.org**: `^2.0.11` is the current npm stable; all htmx 2 attributes used (`hx-get`, `hx-trigger="input changed delay:200ms"`, `hx-push-url`, `hx-swap`, `hx-target="closest table"`) and the `htmx:configRequest` event are current htmx 2 API. However, the app serves a committed vendored `public/htmx.min.js` and `npm run build` is a no-op, so the npm dependency is unused at runtime.
