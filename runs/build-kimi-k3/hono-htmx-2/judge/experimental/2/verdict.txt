# Review: Experimentalness

## What the app actually uses

The measured facts report zero experimental markers (`experimental: []`), and a manual sweep confirms it: no `unstable_*`/`experimental_*` names, no preview flags, no RC/canary dependencies. The entire framework surface is:

- `Hono`, `app.get`, `app.notFound`, `app.onError`, `c.req.query/param/header`, `c.html` — core stable APIs since Hono v1/v2 era (`app/src/app.js:1`, `app/src/app.js:27`, `app/src/app.js:260-266`).
- `html` tagged template from `hono/html` (`app/src/views.js:1`) — stable helper, shipped in Hono v4.0.0 (Feb 2024, per the v4.0.0 release notes) and documented as a fully-supported helper on hono.dev. Not experimental; over 2.5 years stable.
- `serve` from `@hono/node-server` (`app/src/server.js:1`) and `serveStatic` from `@hono/node-server/serve-static` (`app/src/app.js:2`) — the documented, stable node-adapter exports.
- htmx 2.0.11 (`app/package.json`) — this is the **current stable** htmx release (2.0.11, Sep 22 2026, per the official changelog). All directives used (`hx-get`, `hx-trigger`, `hx-swap`, `hx-target`, `hx-push-url` — `app/src/views.js:99-103`, `app/src/views.js:281-285`, `app/src/views.js:324`) and the `htmx:configRequest` event (`app/public/app.js:2`) are long-standing core htmx APIs, not extensions or experimental features.

Version posture is worth noting positively: Hono's v5.0.0-rc.1 exists (released Oct 2026), and the app pins the current stable line `^4.13.14` (`app/package.json`) — released Oct 25, 2026, days before "today". It deliberately does **not** ride the v5 RC. That's the right call for an app that must pass acceptance tests against a moving harness.

No `raw()` is used anywhere in `views.js` — everything interpolates through the auto-escaping `html` template, so there's not even a "sharp edge" API in the rendering path. The one mildly unusual technique — nested `html` fragments inside an attribute value for conditional `aria-sort` (`app/src/views.js:323`) — is a documented property of `HtmlEscapedString` composition, not an experimental feature.

Since every API is long-stable and none needed containment or justification, all three criteria land on the "nothing experimental" anchors. `count` = 0.
