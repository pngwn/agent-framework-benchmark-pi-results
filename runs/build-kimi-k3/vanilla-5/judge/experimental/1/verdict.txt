## Review: experimentalness

The app is deliberately conservative. It's vanilla TypeScript with two dev dependencies (`vite` ^8.3.5, `typescript` ^5.9.3), a ~60-line hand-written Node static server, and browser APIs that have been stable for years.

**Toolchain**: Vite 8 is the current stable major (released 2026-03-12, ~7.5 months old — the Rolldown-based release). It's not experimental, but it is a young major; the app uses only its most basic surface (`defineConfig` and a trivial `configureServer` middleware plugin, `app/vite.config.ts:3-16`), and there's a lockfile pinning exact versions. TypeScript 5.9.3 has been stable since Aug 2025.

**Browser APIs**: everything used is long-stable — `fetch` (`app/src/api.ts:35`), `history.pushState/replaceState` (`app/src/nav.ts:11`), `URLSearchParams`, `innerHTML`, `dataset`, `loading="lazy"` (`app/src/components.ts:18`, Baseline since 2022), `Intl`-backed `localeCompare`, and ES2021-era syntax (`??=` in `app/src/data.ts:11`) against an ES2022 target (`app/tsconfig.json:4`).

**Server**: only long-stable Node builtins — `node:http`, `node:fs`, `node:fs/promises`, `node:path`, `fileURLToPath` (`app/server.mjs:2-6`).

**CSS**: plain custom properties, media queries and grid — no `:has()`, nesting, container queries, or new color functions anywhere in `app/src/style.css`.

The measured facts agree: `experimental: []`, no `unstable_`/`experimental_` names, zero runtime dependencies, and no test runner.
