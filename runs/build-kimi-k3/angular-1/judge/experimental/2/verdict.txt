## Review — Experimentalness

**What's there.** This is a stock Angular 22.2 SSR app (CLI scaffold layout, `outputMode: "server"`, `AngularNodeAppEngine` + Express). Grep across `app/src` finds **zero** `experimental_`/`unstable_`/`provideExperimental*` markers, no config-level experimental flags, and no developer-preview imports. The only APIs younger than a year are things the v21/v22 CLI itself emits (`BootstrapContext`, `allowedHosts`) plus one deliberate use of `RESPONSE_INIT`.

**Newest APIs, verified:**

- `RESPONSE_INIT` — stable since v21 (developer-preview tag removed in PR #60717, merged into the v21 major; angular.dev/api/core/RESPONSE_INIT shows no preview badge). One use, isolated.
- `BootstrapContext` — introduced as stable in v21 (feat #63562, breaking-change note in the 21.0.0-next.3 release notes). Used in `main.server.ts` exactly as the scaffold prescribes.
- `allowedHosts` on `AngularNodeAppEngine` — stable option present since ~v20.3/v21 (backported per angular-cli#33352; current API docs at angular.dev/api/ssr/node/AngularNodeAppEngineOptions).
- `withEventReplay` — stable since v19 (commit 6b23953, PR #57895). Long stable.
- Zoneless change detection runs implicitly (no `zone.js` in `app/package.json` deps) — stable since v20, default for new apps since v21 (angular.dev/guide/zoneless). Baseline of the release, not a reach.
- Everything else (`signal`, `computed`, `effect`, `input`, `afterNextRender`, control-flow `@if/@for/@else`, `ResolveFn`, `TransferState`, `RenderMode.Server`/`ServerRoute`, `mergeApplicationConfig`) is long-stable (v19 or earlier).

**Notably avoided:** Signal Forms and Asynchronous Signals (`resource`/`httpResource`), which were only stabilized in v22 (June 2026) per the v22 release blog — the app uses classic `ResolveFn` resolvers + `HttpClient`/`firstValueFrom` and plain native form controls with event handlers (`app/src/app/home.page.html:7-26`). Also uses `AngularNodeAppEngine` rather than the `CommonEngine` that v22 just deprecated. Conservative and current at the same time.
