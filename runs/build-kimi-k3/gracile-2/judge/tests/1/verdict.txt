## Review — test quality

The app ships **zero tests of its own**: no test files anywhere under `app/` (facts: `tests.files: 0`, `testLoc: 0`), no `test` script in `app/package.json:6-10` (only `dev`, `build`, `start`), and no test runner among the four dependencies. The acceptance suite in `tests/` is the only guard, and it exercises rendered pages end-to-end (I checked `tests/specs/*.spec.mjs` — it's actually fairly thorough), but the prompt's question is what happens once that suite isn't the only guard. The good news: the risky logic is cleanly factored into small pure helpers (`app/src/lib/util.js`, `app/src/lib/data.js`, `app/src/lib/api.js`) that would be trivially testable — the agent just didn't write them.

What a refactor could break with nobody noticing:

- **Pure formatters** (`app/src/lib/util.js:5-43`): `humanize` word-splitting, `latestEnglishFlavorText`'s "last English entry + `\s+` collapse (incl. `\n`/`\f`)" rule, `dexNumber` 4-digit padding, `formatMeasure`'s hectogram/decimetre ÷10 + one-decimal, `valueOrDash`. Each encodes a fiddly spec rule that would fail silently.
- **URL filter/pagination state** (`app/src/routes/index.js:31-40`): `parseInt(...)||1` then `Math.max`/`Math.min` clamping of `page`, silent-fallback for invalid `type`/`generation` params, and the 48-per-page slice at lines 78-81. Off-by-ones and clamp regressions land directly on user-visible pages.
- **Species mapping** (`app/src/lib/data.js:60-83`): the `< 10000` alternate-form cut, dedupe-keeps-first-`extra` (which carries the hidden-ability flag), and dex-number sort. Breakage means duplicate cards, links to alternate forms, or dropped "Hidden ability" notes — across four routes at once.
- **Moves grouping/ordering** (`app/src/routes/pokemon/[name].js:108-160`): the `METHOD_ORDER` rank + alphabetical comparator, `level-up` sort by level-then-name, and default game = highest `order` via `versionGroups.at(-1)` (a `NaN` comparator lurks if `order` is ever missing). Untested.
- **Client-side sorting** (`app/src/routes/pokemon/[name].client.js:45-77`): DOM-text sorting with missing-values-last in both directions and `aria-sort` reset. The Level column shifting cell indices per table is a classic regression.
- **Fetch-and-swap enhancement** (`app/src/routes/index.client.js:34-52`): non-200 responses silently no-op (`getElementById('results')` returns null → nothing happens while the URL changed), popstate resyncs selects. Only guarded by the acceptance suite's happy paths.
- **API client error paths** (`app/src/lib/api.js:19-57`): promise-cache eviction on failure is done right, but `idFromUrl` **throws** on a malformed URL and would 500 the whole page; a non-404 API error propagates unhandled.
