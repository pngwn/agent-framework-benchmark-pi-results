## Review: experimentalness

**Framework context (verified today, 2026-10-30).** The current stable Qwik release is **1.20.3** (patch line released 2026-10-25); Qwik **2.0 is at RC** (`@qwik.dev/core@2.0.0-rc.3/4`). The app pins `"@builder.io/qwik": "^1.20.3"` (`app/package.json:12-13`) — i.e. exactly the latest stable line, not the RC.

**What the app actually uses.** The import surface is tiny and entirely core-stable: `component$`, `useStyles$`, `Slot` (`app/src/root.tsx:1`, `app/src/routes/layout.tsx:1`), `useSignal` (`app/src/components/moves-table.tsx:1`), `routeLoader$`/`useNavigate`/`useDocumentHead`/`DocumentHead`/`RequestHandler` (all routes), `renderToStream` (`app/src/entry.ssr.tsx:1`), and the node middleware `createQwikCity` (`app/src/entry.node-server.ts:1`). I checked the shipped 1.20.3 typings: `createQwikCity` is `@public` (jsdelivr, `lib/middleware/node/index.d.ts`), and none of the v1-deprecated APIs (`useResource$`, `useWatch$`, `useRef`, `loader$`, `useEndpoint`, per the official Deprecated Features page) appear anywhere in `app/src`.

**The one genuine flag.** `nodeServerAdapter` (`app/adapters/node-server/vite.config.ts:1,13`) is marked `/** @alpha */` in the shipped 1.20.3 typings and rendered by the docs as "This API is provided as an alpha preview… Do not use this API in a production environment." Important mitigating evidence: the framework's own starter for Node deployment (`QwikDev/qwik`, `starters/adapters/node-server/.../vite.config.ts`) uses literally the same call `nodeServerAdapter({ name: "node-server" })` — this app mirrors the official scaffold nearly line-for-line, adding only `@qwik-city-plan` to the rollup inputs. So it's an alpha-labeled API that is nonetheless the sanctioned production deployment path; there is no stable-flagged alternative for this job.

**The measured "experimental" marker is a false positive.** `app/server/q-BrBSDCN_.js:15` is Qwik core's own bundled dev-mode QRL-serialization warning string, inside **build output** (the `nodeServerAdapter` emits to `server/`; `app/package.json:7` starts it). No experimental API use exists in `app/src`.

**Containment.** The single alpha API is one import + one call in one adapter config file; swapping it touches nothing else. The server wiring it produces is isolated to `app/src/entry.node-server.ts` (35 lines, uses only `@public` middleware).
