## Review

**Idiom.** This is textbook Qwik City: `routeLoader$` per route with URL-as-state (`app/src/routes/index.tsx:11`), 404 via `status(404)` + null in loaders (`app/src/routes/pokemon/[name]/index.tsx:35`), `head` functions resolving loader values with `resolveValue` (`app/src/routes/pokemon/[name]/index.tsx:318`), standard `root.tsx`/`layout.tsx`/`entry.node-server.ts` adapter shape (`app/src/entry.node-server.ts:8`), `[...all]` catch-all with `onGet` 404 (`app/src/routes/[...all]/index.tsx:8`). Pins `^1.20.3` = current stable. The only mildly home-grown bits are the raw `setTimeout` debounce in a signal (`app/src/routes/index.tsx:105`) where `useTask$`+tracked signal would be more idiomatic, and the inline derived sort in render (`app/src/components/moves-table.tsx:56`) instead of `useComputed$`.

**Correctness.** Careful work: rejected promises evicted from cache to allow retry (`app/src/lib/api.ts:44`), page clamping (`app/src/routes/index.tsx:57`), invalid `?game=` falls back to the default version group (`app/src/routes/pokemon/[name]/index.tsx:69`), alternate forms filtered at `>= 10000` (`app/src/lib/data.ts:90`), `encodeURIComponent` on all path params. Remaining minor items: filter handlers close over stale loader values so a pending debounced search can navigate with an outdated `type`/`generation` (`app/src/routes/index.tsx:102-106`); `fetch` has no timeout, so a hung API hangs SSR (`app/src/lib/api.ts:36`); the limiter can briefly overshoot its cap (`app/src/lib/api.ts:16-24`). Nothing serious.

**Abstractions.** Small focused libs (`api`/`data`/`format`/`urls`), with the server/client boundary explicitly reasoned about (`app/src/lib/urls.ts:1`, `app/src/lib/api.ts` server-only) — I verified no `process.env` leaked into `dist/` client bundles. Nits: whole raw records carried on `TypeInfo.record: any` (`app/src/lib/data.ts:8`) and the `typeEn` map rebuilt in three routes (`app/src/routes/moves/[name]/index.tsx:36`).

**Readability.** Good names, why-comments where they matter (`app/src/lib/api.ts:5-10` concurrency pool, `app/src/lib/data.ts:93` fallback rationale), consistent file layout. The main drag is pervasive `any` for API payloads (`app/src/lib/api.ts:35`) and the ~180-line Pokémon loader.
