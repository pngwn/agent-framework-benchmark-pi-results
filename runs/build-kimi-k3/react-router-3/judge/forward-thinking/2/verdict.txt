## Review notes (dimension: forward-thinking)

**Currency of APIs.** The app is pinned to React Router `8.5.1` and React `19.3.1` — both exactly the latest stable releases today — and it uses the v8-era conventions throughout: all imports from `react-router` (not the removed `react-router-dom`), `meta({ loaderData })` (not the removed `data` arg), `tsconfig` target/lib ES2022 matching the v8 template, `"type": "module"`, no future flags (v8 removed all of them), no unstable/`UNSAFE_` APIs, and it correctly avoided the view-transition APIs deprecated in 8.5.0. Framework-mode structure is idiomatic: `routes.ts` with `route()`/`index()`, generated `Route` types in every route module, root `Layout` export so `ErrorBoundary` doesn't re-render the document shell, `.server.ts` suffix to keep the data layer out of the client bundle, and a documented `shouldRevalidate` opt-out on the home route. This is a 5.

**Platform.** Good reach for the platform: `fetch`/`URL`/`URLSearchParams`, `localeCompare`, logical CSS properties (`margin-inline`, `padding-block`), CSS custom properties, native `type="search"`/`<select>`/`<caption>`/`aria-sort`, `image-rendering: pixelated`. Two gaps: no `request.signal` propagation into the API client (`fetch(url)` with no signal, and no way to pass one), and manual href string building (`return search ? \`/?${search}\` : "/"`) instead of `Link`'s `to` object / the `href()` helper. Score 4.

**Dependencies.** Five runtime deps, all current and all genuinely needed — `isbot` is required by the framework's generated default server entry (confirmed at `app/build/server/index.js:5`), so it is not dead weight. No CSS framework, no state library, no icon fonts. Vite resolved to 7.3.7 (previous major; still security-patched and inside `@react-router/dev@8.5.1`'s peer range `^7 || ^8`). Score 5.

**Churn resistance.** The strongest part of the design: all API access is behind one module (`lib/pokeapi.server.ts`) with routes never calling `fetch` directly, and a clean client/server split. But the API boundary is untyped (`apiGet<T = any>` plus pervasive `as any[]` casts in every loader), not-found is handled through four overlapping mechanisms, sprite URL rules are duplicated in two modules, and the artwork fallback constructs a URL the API never advertised. Score 4.
