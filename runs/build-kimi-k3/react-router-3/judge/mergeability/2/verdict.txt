## Review

A clean, recognisably idiomatic React Router 8 framework-mode app: route config in `app/routes.ts`, typed route modules (`Route.LoaderArgs`/`MetaArgs`/`ComponentProps`), a `Layout` export in `root.tsx`, `.server.ts` naming to fence server code, `data(..., { status: 404 })`, and a pinned current stable version (8.5.1). The data layer (`lib/pokeapi.server.ts`) has a clear server/client boundary and deliberate caching.

The main deviations from the framework's documented guidance: 404s are returned as `notFound` flags and branched in components rather than the documented `throw data(..., {status:404})` + route `ErrorBoundary` pattern (repeated across four routes); home-page filtering is done client-side from a local `q` state rather than in the loader, which introduces a real URL/state desync when the URL changes while the route stays mounted; and the API layer is `any`-typed throughout. Several small helpers are duplicated (`num`, the type-badge markup, two `spriteUrl` variants).
