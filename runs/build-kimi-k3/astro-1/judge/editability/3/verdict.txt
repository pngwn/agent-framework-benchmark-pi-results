# Review: editability of `app/`

The app is a clean, idiomatic Astro 7 (SSR, `@astrojs/node`) project: one flat data module (`app/src/lib/pokeapi.js`), four small presentational components, and one route file per page. That baseline is very good. The two real liabilities are (1) the "build a Pokémon card" logic existing in **three** places, and (2) the home page's query-string knowledge duplicated between server frontmatter and the inline client script. Everything else is localized and easy to find.

**Scenario walkthrough**

1. **Remove Abilities** — delete `app/src/pages/abilities/[name].astro`; the nav (`app/src/components/Layout.astro:23-25`) doesn't link to it, so the only inbound references are the Abilities section links on `app/src/pages/pokemon/[name].astro:220`. Two files, both obvious. Clean.
2. **Deoxys sprite bug** — the sprite is derived in `app/src/lib/pokeapi.js:148` (`cardsFromPokemonRefs`), again inline in `app/src/pages/abilities/[name].astro:31`, and again in `app/src/pages/index.astro:78`. A fix (e.g. fetch the species' default variety instead of the ref's own Pokémon record) must land in all three. This is the weakest seam in the codebase.
3. **Sort cards by name** — sort sites are `app/src/lib/pokeapi.js:151` and `app/src/pages/abilities/[name].astro:35` (home page's order is spec-pinned, so arguably untouched). Two edits, or first refactor to one helper.
4. **Items section** — copy `app/src/pages/moves/[name].astro`; `Layout`, `Section`, `NotFound`, `PokemonCard` and the whole `pokeapi.js` helper set are reusable as-is. But the try/catch-404 scaffold and the facts `<dl>` markup are copy-paste, not shared. Moderate.
5. **API base URL / caching** — `app/src/lib/pokeapi.js:5` and `:8` are the only places that know. Excellent.

**Minor notes on idioms (verified current):** `Astro.response.status = 404` plus the `!data ?` template branch is fine on Astro 7.4.4 (the current stable), though it's repeated verbatim in four route files; 7.4's `notFound()`/middleware would DRY it. `chainToHtml` builds HTML by string concatenation with hand-rolled escaping (`app/src/pages/pokemon/[name].astro:36-44`) — works, but it's the least "Astro-like" and least restyleable code in the repo.
