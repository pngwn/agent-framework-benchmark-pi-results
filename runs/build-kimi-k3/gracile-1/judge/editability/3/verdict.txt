# Review: Editability of the Gracile + Lit Pokédex

The app is a clean Gracile 0.11 (current stable) server-output project: `vite.config.ts` with `output: 'server'`, an Express adapter in `server.js`, and per-route `defineRoute({ handler, document, template })` files with `.client.ts` companions. Data fetching is funneled through one module (`src/lib/api.ts`), rendering helpers through two (`components.ts`, `format.ts`), and reference→card conversion through one (`species-cards.ts`). That structure is what makes the scenarios below mostly painless.

## Scenario walkthroughs

1. **Remove Abilities.** Delete `app/src/routes/abilities/` and the single Abilities section in `app/src/routes/pokemon/[name].ts:315-340`; optionally drop `.abilities-list` in `app/public/styles/global.css:402`. No nav links exist (nav is spec-fixed), and grep shows no other references. Trivial.
2. **Sprite bug (Deoxys-class).** Sprite is taken from the fetched Pokémon record's `sprites.front_default` in **two** independent places: `app/src/lib/species-cards.ts:42` (covers the Moves/Abilities/Types lists) and `app/src/routes/index.ts:125` (home page builds its own `CardData`). One fix covers 3 of 4 lists; home needs a second edit.
3. **Sort all card lists by name.** Two sort sites: `species-cards.ts:46` and `index.ts:106` (the species list itself). Both one-liners with the sort key already available, but the same intent lives in two files.
4. **Add an Items section.** New `routes/items/index.ts` (model: `routes/types/index.ts`) + `routes/items/[name].ts` (model: `routes/moves/[name].ts`). Everything substantive — `api`, `document`, `section`, `cardList`, `speciesCards`, `notFoundTemplate`, format helpers — is reused; only the declarative route glue is copied.
5. **API base URL / caching change.** One file: `API_BASE` at `src/lib/api.ts:6`, the cache at `:72`, concurrency at `:14-32`, and the `/api/v2` prefix assumption at `:90` all live in `api.ts`. No route knows the URL shape beyond relative API paths.

## Notable issues

- Card-data construction is duplicated between the home handler and `species-cards.ts` — the exact seam where a sprite/sort bug would need two fixes.
- The sortable-tables feature is split across two files with an implicit `data-v`/`data-n`/`data-missing` attribute contract (`routes/pokemon/[name].ts:62-90` ↔ `[name].client.ts:34-42`), with no shared constant or comment tying them.
- Every route template does `context.props.GET as any`, discarding the type the handler established; every param route repeats the same stub-guard/try-catch/404 block verbatim (4×).
