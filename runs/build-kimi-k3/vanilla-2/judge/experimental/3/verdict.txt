The app is maximally conservative: server-rendered HTML from Node's long-stable `http`/`fs`/`path`/`url` modules, plain `fetch`, the History API, `URLSearchParams`, `localeCompare`, and a custom `vite.config.js` that only sets `build.manifest`. The single dependency, Vite `^8.3.5`, is the current stable major (Vite 8 stable since March 2026; 8.3.5 is the latest `npm dist-tag`), and the app doesn't opt into Vite 8.1's experimental bundled dev mode — its `dev` script bypasses the Vite dev server entirely. The CSS uses only `@import` and one `@media` query; no `:has()`, `oklch`, `@layer` or other modern-CSS bets. No `experimental` markers, no unstable flags, nothing to contain.
