## Review

I read `SPEC.md`, all 22 source files under `app/src`, the adapter/server entry points, and the shared CSS, and verified the framework baseline: `@builder.io/qwik@1.20.3` / `@builder.io/qwik-city@1.20.3` is the current stable line (released 2026‑10‑25; v2 is still at RC). The app is a textbook Qwik City structure: `routeLoader$` for all server data, typed props into small components, client state only where it belongs (`moves-table.tsx` sorting), the standard `adapters/node-server` + `src/entry.node-server.tsx` layout. Nothing deprecated or non-idiomatic in the framework usage. The main editability weakness is that "turn a bunch of Pokémon references into a list of cards" — dedupe, alternate-form exclusion, sort by dex, sprite, species-name mapping — is copy-pasted in three route loaders and a fourth variant on the home page, so anything that changes *card semantics* rather than *card rendering* lands in four files.
