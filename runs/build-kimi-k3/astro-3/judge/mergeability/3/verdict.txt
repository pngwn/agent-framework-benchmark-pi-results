## Review summary

This is a clean, current-version Astro 7 app (astro ^7.4.4 / @astrojs/node ^11.1.9 are the latest stable releases as of 2026-10-30, verified against the changelog). It uses `output: 'server'` + standalone Node adapter exactly as the docs prescribe, does all data loading in frontmatter with top-level await, handles 404s via `Astro.response.status = 404` + a `404.astro`, and keeps a small, well-bounded `lib/` layer (`api.js` fetch+cache+bounded-concurrency, `data.js` API shaping, `format.js` pure helpers). Race handling in the client script (`seq` guard, `app/public/js/home.js:33-35`), min-level move dedupe, and default-variety/species-name resolution (`app/src/lib/data.js:56-70`) show real care about the tricky parts of the API's shape. The deductions are consistent and modest: the 404 try/catch block is copy-pasted across four dynamic routes, frontmatter leans on `any` throughout, and the two client scripts live as un-bundled `public/` files loaded via `is:inline` rather than Astro's processed/bundled `<script>`.
