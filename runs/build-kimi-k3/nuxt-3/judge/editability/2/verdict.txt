**How the code is organized (relevant to editability):**
- All data access goes through one module, `app/app/utils/poke.ts` (auto-imported), with a single in-memory cache (`fetchApi`, poke.ts:66-76) and a single `spriteUrl` helper (poke.ts:90).
- Presentational components are narrow: `PokemonCard` (card + optional types), `MovesTable` (rows/caption/hasLevel), `EvolutionNode` (node), `NotFound`.
- The one card-model builder, `cardsFromPokemonRefs` (poke.ts:233-257), covers the move/ability/type lists — but the home page builds its own inline copy at `index.vue:104-110`.
