## Review summary

This is a **Nuxt 4.6.3** app — and 4.6.3 is the exact current stable, released 2026-10-27 (verified against nuxt/nuxt releases). The layout follows the Nuxt 4 `app/` srcDir convention, uses `<script setup lang="ts">`, auto-imports, `useAsyncData`/`useHead`/`defineNuxtPlugin`, type-based `defineProps`, and pins Vue 3.5.44 (latest stable; 3.6 is still RC) and vue-router ^4.5. Dependencies are exactly the official scaffold's three. The strongest forward-looking property is the single data layer (`app/app/utils/poke.ts`) that all five pages consume through plain serializable models.

The main things keeping it from top marks: the API boundary is typed as `any` (records re-cast inline in pages), the 404-status code is set by reaching into the Node adapter (`event.node.res.statusCode`, hand-rolled in five files) instead of a portable helper or Nuxt's error pipeline, the API base URL is sourced twice (`process.env` at module scope plus `runtimeConfig` via plugin), and `compatibilityDate` is pinned ~22 months in the past, which freezes pre-2025 behavior — relevant now that Nuxt 4.6 ships the `nuxt/server` web-standard surface as the on-ramp to Nuxt 5 (per the official v4.6 announcement).
