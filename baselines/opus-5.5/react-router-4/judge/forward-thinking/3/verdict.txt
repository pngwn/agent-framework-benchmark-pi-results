## Review notes

**Currency.** This app is unambiguously on the current generation: React Router 8.5 (`app/package.json:5-21`), React 19.2, Vite 8 — and it uses the v8-era conventions rather than v7 holdovers: imports come from `react-router` (not the removed `react-router-dom`, `app/app/root.tsx:1-9`), `meta` uses `loaderData` rather than the field removed in v8.0.0 (`app/app/routes/move.tsx:12-14`), route modules use generated `./+types/<route>` types (`app/app/routes/home.tsx:2`), and the root uses the current `Layout` export + `ErrorBoundary` pattern (`app/app/root.tsx:18,51`). It even uses Vite 8's native `resolve.tsconfigPaths` instead of the third-party plugin (`app/vite.config.ts:6-8` — Vite 8 feature, confirmed via vitejs/vite#494 and the Nx docs). Nothing deprecated in 8.5.0 (view transitions) is used. `react-router-serve` is still the maintained official server (patched in 8.5.1), and `isbot` is expected by the framework's default entry server since the app ships no custom `entry.server.tsx` (remix-run/react-router#15668, #13782).

**Platform.** Global `fetch` in loaders (no polyfill, Node 24), `URL`/`URLSearchParams` for query handling (`app/app/routes/home.tsx:14-17`, `67-75`), CSS custom properties throughout including computed per-type colors (`app/app/routes/types.tsx:26`, `app/app/components/ui.tsx:7`), `loading="lazy"` + explicit dimensions on sprites (`app/app/components/ui.tsx:29`), and a `<noscript>` GET-form fallback (`app/app/routes/home.tsx:112`). Gaps: server fetches have no `AbortSignal.timeout`, and `idFromUrl` regex-parses URLs where `new URL(url).pathname` is the platform tool (`app/app/lib/format.ts:16`).

**Churn resistance.** The strongest part of the design: every PokeAPI concern — base URL, caching, 404 mapping, API shapes, localization, card derivation — lives behind one module (`app/app/lib/api.server.ts`), loaders return plain serializable objects, and route types come from typegen, so a framework upgrade touches generated types, not hand-written ones. Weak spots: `spriteUrl` hardcodes the media URL pattern rather than using the `sprites.front_default` URL the API actually returns (`app/app/lib/api.server.ts:165-167`), the in-memory cache never evicts expired entries, and the "alternate form" cutoff `10000` is duplicated as a magic number (`app/app/routes/home.tsx:44`, `app/app/lib/api.server.ts:171`).
