Remove Abilities.** Self-contained route dir (`app/src/routes/abilities/[name]/` — 2 files, deleted as a unit), and no nav links to it (`app/src/routes/+layout.svelte:23-26` only links Pokémon and Types, as the spec requires). The only inbound reference is the Abilities *section* on the Pokémon detail page (`app/src/routes/pokemon/[name]/+page.svelte:95-103`, data built at `+page.server.ts:92-95,167`) — inherent domain coupling, easy to find. Residue if you're sloppy: `Card.hidden` (`app/src/lib/util.ts:34`), the hidden-ability span in `CardList.svelte:33-35`, and the `extra` callback in `pokemonCards` become dead. **Difficulty 4.**

**2. Sprite bug (Deoxys).** Every card list funnels through one function: `spriteUrl()` at `app/src/lib/server/api.ts:95-97`. The home page builds cards inline but still calls it (`app/src/routes/+page.server.ts:32`); moves/abilities/types all go through `pokemonCards` (`api.ts:195`). One fix covers all four lists. If the fix needs species→default-variety resolution, the species index (`getSpecies`, `byId`) is already in the same file. **Difficulty 5.**

**3. Sort card lists by name.** All card lists render through one component (`CardList.svelte`), so a UI-side sort is a one-file change; a data-side sort touches two places (`pokemonCards`'s `sort` at `api.ts:197` and the home page's slice at `+page.server.ts:30`). **Difficulty 4.**

**4. Add Items shaped like Moves.** Almost all heavy lifting is shared and reusable: `get`/`getOrThrow`/`englishName`/`latestFlavorText`/`pokemonCards` in `api.ts`, `CardList`, `TypeBadge`, global scaffolding classes (`.panel`, `.page-title`, `.facts`, `.count` in `app/src/app.css:48-98`), and the 404 pattern (`error(404)` in every load). You copy two thin route files (~60 LOC, e.g. `moves/[name]/+page.server.ts`) and adapt fields. **Difficulty 4.**

**5. Change API base URL / caching.** Grep confirms exactly one file knows about either: `app/src/lib/server/api.ts` — `apiBase()` (:9-12), `resolveUrl` (:24-28), `CACHE_TTL_MS` (:6), the cache map and `get` (:33-61), `spriteUrl` (:95). Routes never see raw URLs. **Difficulty 5.**

## Judgment

This is a well-seamed codebase for its size: a single `lib/server/api.ts` owns the data source and domain indexes, `lib/util.ts` owns formatting, three small components own rendering, and route files are thin server-load + template pairs passing typed `$types` data down. What keeps it off 5s: card construction is duplicated between the home load and `pokemonCards`, `MoveTable` re-declares the `Row` shape its caller builds, and there's mild optional-field/boolean-flag creep (`Card.types/hidden`, `MoveTable.showLevel`, `TypeBadge.link`) that would leave dead code behind on feature removal.
