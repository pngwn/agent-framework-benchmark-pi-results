## What the app actually uses

**Nothing currently experimental.** Zero `unstable_`/`experimental_` names, no experimental config flags, and notably it stays away from SvelteKit 3's one explicitly-not-ready feature (remote functions — "Not quite ready. But it's our top priority!" per the [SvelteKit 3 announcement](https://svelte.dev/blog/sveltekit-3-is-here), Oct 1 2026).

**Recently-stable APIs (stable in the last ~6 months):**

1. **`defineEnvVars` / `$app/env/private`** — `app/src/env.ts:1` defines `API_BASE_URL` with a default and trailing-slash normalization; consumed in one place at `app/src/lib/server/api.ts:2`. Docs confirm this was "added in SvelteKit 2.62 as an experimental option" and that `$env/*` is now the *deprecated* legacy path in SvelteKit 3 (svelte.dev/docs/kit/environment-variables). This is where the framework is going, not a gamble — using `$env/static/private` would have been the dated choice.
2. **`goto(url, { reset: false })`** — `app/src/routes/+page.svelte:45` and `app/src/routes/pokemon/[name]/+page.svelte:111`. The SvelteKit 3 replacement for `noScroll`/`keepFocus` (svelte.dev/e/kit/goto_options_removed), needed here so the search/filter UI doesn't drop focus and scroll on `goto` navigations. Open upstream issue #16990 shows the option's semantics may still churn — a minor risk.
3. **`compilerOptions.runes` as a function** — `app/vite.config.ts:8-10`, matching the pattern the Svelte CLI itself generates; merged in svelte PR #17951 (March 2026) as the replacement for `dynamicCompileOptions`.
4. **The SvelteKit 3 platform itself** — `app/package.json:8-19` pins Kit ^3.1, TS 6, Vite 8, vite-plugin-svelte 7, adapter-node 6: exactly the required minimums from the migration guide. Stable, but only four weeks old (Oct 1 2026), so the whole app rides a very fresh major.

**Long-stable:** Svelte 5 runes/snippets/event attributes (stable Oct 2024) — `app/src/lib/components/Section.svelte:2`, `app/src/routes/+page.svelte:80`; `page` from `$app/state` (Kit 2.12, Feb 2025) — `app/src/routes/+error.svelte:2`; `afterNavigate`/`goto`/`error()` throughout `app/src/lib/server/api.ts:3,36,38`.
