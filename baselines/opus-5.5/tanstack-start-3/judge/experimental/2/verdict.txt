## Review: experimentalness

**What the app uses.** The measured facts show `experimental: []` and a `grep` for `unstable|experimental` across `app/src` confirms it: there are no experimental flags, no `unstable_`/`experimental_` names, no canary/preview packages. Every framework API in use is part of the current stable surface:

- `createServerFn({ method: 'GET' }).validator(...).handler(...)` in `app/src/server/functions.ts:39,50,125,138,152,163` — this is exactly the current stable API, including the freshly renamed `.validator()` (the RC-era `.inputValidator()` was removed before 1.169; the app already uses the new name). Calling convention `fn({ data: {...} })` matches the current Server Functions guide verbatim.
- `HeadContent` / `Scripts` from `@tanstack/react-router` (`app/src/routes/__root.tsx:2,41,65`) — the current SSR head/document APIs in the stable release, not the older deprecated `Meta`/`Links` exports.
- `notFound()` thrown from loaders with `notFoundComponent` (`app/src/routes/pokemon.$name.tsx:19,24` and the other three detail routes) — documented pattern.
- `srvx` + `staticMiddleware` production server (`app/server.mjs:7,8`) serving `dist/server/server.js` — srvx 1.x is stable, and TanStack's own e2e projects and examples use srvx to serve the Start production build (router PR #5915, Nov 2025), so this is the idiomatic self-hosting path, not a novel reach.

**How new is "stable" here.** The recently-stable angle is significant but not experimental: TanStack Start 1.169 is the *first* stable release of the framework, announced 2026-10-13 — two and a half weeks before today — and the app pins `^1.169.4` (`app/package.json:14-15`), the newest stable patch. TypeScript is `^7.0.2` (stable 2026-07-08, ~3.5 months old). Vite 8 (stable 2026-03-12) is required by Start 1.169 anyway. So the entire central stack is "recently-stable," but nothing is experimental/preview/RC/canary.

**One internal-API reach:** `app/src/routes/__root.tsx:13` reads `m._notFound` on route matches to pick the not-found title — an underscore-prefixed internal property. `m.status === 'notFound'` alone would do; the `_notFound` fallback leans on a private field.

**Containment** is good: all eight server functions live in one module (`app/src/server/functions.ts`), all PokeAPI fetch/caching logic in `app/src/server/pokeapi.ts`, and the custom server is isolated in `app/server.mjs`. If a Start API shifts in a minor release, the blast radius is small.
