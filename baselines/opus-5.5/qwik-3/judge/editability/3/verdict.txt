## Review

**Structure.** The app follows the standard Qwik City layout: `src/routes/*` for pages, `src/lib/api.ts` as the (explicitly server-only) data layer, `src/lib/format.ts` for pure helpers, and small presentational components. Data shaping lives entirely in `routeLoader$`s; components are dumb and take narrow props (`CardData`, `MoveRow`, `Section`/`TypeBadge` props). Server/client separation is clean.

**Scenario walk-throughs:**

1. **Remove Abilities** — delete `app/src/routes/abilities/`; the nav (`app/src/routes/layout.tsx:19-28`) never mentions it. The only inbound links are the spec-required Abilities section on the Pokémon page (`app/src/routes/pokemon/[name]/index.tsx:214-221`), and `card.hidden`/the `extra` callback in `cardsForPokemon` (`app/src/lib/api.ts:99-114`, used only at `routes/abilities/[name]/index.tsx:21`) plus the `Hidden ability` note (`app/src/components/pokemon-cards.tsx:27`) become dead code.
2. **Sprite fix** — sprite URLs are built by exactly one function, `spriteUrl` (`app/src/lib/api.ts:47`), and card lists for moves/abilities/types all flow through `cardsForPokemon` (`api.ts:99-114`), so one fix covers all reference-based lists. The home page builds cards separately (`app/src/routes/index.tsx:40-49`) but is keyed on species IDs already, so it needs only verification — that second construction site is the one real duplication in the app.
3. **Sort by name** — every card list (home, move, ability, type) renders through `PokemonCards`/`PokemonCard` (`app/src/components/pokemon-cards.tsx:20-31`); sorting inside that component (or a prop on it) is a one-file change covering all four.
4. **Items section** — all the machinery (`api`, `orDash`/`englishName`/`title`, `Section`, `NotFound`, `PokemonCards`) is reusable, but the detail-route skeleton (loader + `status(404)` + `head` with `resolveValue`) is copy-pasted verbatim across moves/abilities/types (`routes/moves/[name]/index.tsx:11-46` vs `routes/abilities/[name]/index.tsx:8-23` vs `routes/types/[name]/index.tsx:17-33`), so Items becomes the 4th copy of ~30 lines of boilerplate.
5. **Data source change** — base URL, cache TTL/size, 404 semantics and the `/api/v2/` prefix all live in `app/src/lib/api.ts` alone (`:9`, `:7-8`, `:21`, `:37`); `spriteUrl` uses the same `apiBase()`. One file.
