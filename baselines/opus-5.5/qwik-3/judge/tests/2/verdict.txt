That's a real loss here, because the codebase is full of exactly the kind of pure, refactor-hostile logic that cheap unit tests would protect:

- `app/src/lib/format.ts:12-47` — `humanize`, `dexNumber`, `idFromUrl`, `latestFlavorText` (whitespace collapse + "latest English"), `orDash`. All trivially unit-testable, all spec-critical.

- `app/src/lib/api.ts:121-133` — `cardsForPokemon`: alternate-form exclusion (`id < 10000`), dedup by species id, name fallback. The acceptance suite's live-overlay test touches this once; a refactor bug would mostly pass.
- `app/src/lib/api.ts:105-149` — `speciesIndex`: type-slot aggregation (`slots[entry.slot - 1]` with sparse arrays) and the generation map driving all filtering on `/`.
