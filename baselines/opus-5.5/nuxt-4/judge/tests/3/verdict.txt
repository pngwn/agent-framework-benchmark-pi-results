## Review: test quality

**The agent wrote zero tests of its own.** `app/package.json` defines only `dev`/`build`/`start`/`postinstall` — no test runner, no test script, no dev dependency for testing (`app/package.json:6-11`), and grep confirms no `*.test.*`/`*.spec.*` files anywhere under `app/`. That matches the measured facts (`tests.files: 0`). The only guard this code has is the external acceptance suite in `tests/`, which the agent didn't write.

What makes this costly is that the app is *dense with exactly the kind of logic that breaks silently in a refactor*:

- **URL/filter/pagination state** — `app/pages/index.vue:36-60`: the search-match predicate (`humanize(...).toLowerCase().includes(needle)` against the *input* value, not the URL), the page clamp (`Math.min(Math.max(n, 1), totalPages)`), and `setFilter`'s rebuild-from-scratch query that intentionally drops `page` when a filter changes. None of it is asserted anywhere in `app/`; breaking the "filter change resets to page 1" rule or the out-of-range-page clamp would go unnoticed locally.
- **Move table sorting** — `app/components/MoveTable.vue:60-77`: missing-values-last in both directions, the `sign * compare` flip, the default "level, then name" order, and the `aria-sort` toggle. This is hand-rolled comparator code with a spec'd edge case (`null` handling); it's the single most regression-prone component in the app and has no test.
- **Alternate-form exclusion / card mapping** — `server/utils/pokeapi.ts:88-105` (`cardsFor`): the `id > 10000` cut, the species-name fallback (`species.get(id) ?? ref.name`, so `deoxys-normal` renders as `Deoxys`), dedupe and id sort. The acceptance tests cover it today, but a data-layer refactor (e.g. switching the server client to a batch endpoint) would be flying blind.
- **The moves aggregation** — `server/api/pokemon/[name].get.ts:33-60`: game ordering by `order ?? Infinity`, the fragile `[...gameNames][i]` index alignment between a `Set` and its mapped records, the per-`(game|method|level)` dedupe key, and stat-label mapping. The `Set`→array index correlation works only because both derive from the same spread — one refactor away from mislabelled games.
- **Caching and 404 semantics** — `server/utils/pokeapi.ts:14-40`: the 60s TTL cache, error-eviction on rejection, and the "404 → null, other errors throw" contract that `pokeapiOr404` and the whole not-found path depend on. A caching bug here surfaces as stale or wrongly-cached 404s.
- **Text rules** — `latestFlavorText` / `englishShortEffect` (`server/utils/pokeapi.ts:64-78`): "last English entry" and whitespace collapsing; `humanize`/`dexNumber`/`orDash` (`app/app/utils/format.ts:1-11`) are pure one-liners that cost nothing to pin down and are shared by every page.

The pure helpers in `format.ts` and `pokeapi.ts` would have been a cheap, high-leverage place to start — Vitest with Nuxt's `@nuxt/test-utils` is the current idiomatic choice and would have covered the sorting and URL-state logic with maybe a dozen unit tests.
