# Review: Editability of the Pokédex app

**Framework check:** React Router 8.5.x is the current stable line (v8.5.1 shipped 2026-10-27), and the app is on `^8.5.0` with `app/routes.ts` route config, typed `+types` route modules, SSR enabled, and a `.server.ts` server-only data module — all current framework-mode conventions. Nothing deprecated in v8 is in use (`react-router-dom`, old `meta` `data` args, etc.).

## Scenario walkthroughs

**1. Remove Abilities.** Delete `routes/ability.tsx`, drop one line in `routes.ts:11`, and remove one `<Section title="Abilities">` plus its loader mapping in `routes/pokemon.tsx:264`/`:160`. There's no nav link to remove (`root.tsx:22` only has Pokémon and Types). However, ability-specific plumbing leaks into shared files: `Card.hidden` (`lib/types.ts:9`), the "Hidden ability" note (`components/PokemonCards.tsx:23`), the `extra` callback parameter of `pokemonCards` (`lib/api.server.ts:139`, used only by `ability.tsx:27`), and `.card__note` CSS (`app.css:219`) all become dead code. Contained, but not a pure delete-and-go.

**2. Sprite bug (Deoxys).** Every card list funnels through `speciesCard` (`lib/api.server.ts:119`) → `spriteUrl` (`:39`), which both `home.tsx:40` and `pokemonCards` (`:136`) use. One fix in `spriteUrl` covers home, move, ability and type pages. The only other image path is the hero artwork, which correctly comes from API data (`pokemon.tsx` `artwork` field), so it's genuinely separate. This is the best-designed seam in the app.

**3. Sort every card list by name.** Two places: the sort in `pokemonCards` (`lib/api.server.ts:148`) covers moves/abilities/types, but the home page's order comes from `index.species` (sorted by id in `getIndex`, `:87`) and is never re-sorted in `home.tsx:66-69` — it needs its own sort. Findable, but not one place.

**4. Add Items like Moves.** Reusable: `apiOr404`/`getIndex`, all of `lib/format.ts`, `Section`, `PokemonCards`. Not reusable: the detail-page skeleton (title + h1 + facts `<dl>` + Effect section + "N Pokémon" section) exists as near-duplicate JSX in `move.tsx:48-77` and `ability.tsx:37-51`, and each route declares its own inline API record types (`move.tsx:8` vs `pokemon.tsx:43` both declare `type Move` with divergent fields). You'd copy `move.tsx` and adapt ~half of it, plus a line in `routes.ts`. Moderate copy-paste.

**5. Change API base URL / caching rules.** `API_BASE_URL` (`api.server.ts:7`), `TTL_MS` (`:8`), the cache (`:11-18`) and the sprite URL derivation (`:39`) all live in one module; `server.mjs` only knows the app's own port. Trivial.
