## Review summary

I read the whole app: config, server entry, root, all 7 routes, 4 components, and the lib modules. Then I verified framework status against the live changelog (reactrouter.com/changelog) and release notes, since my training data predates React Router v8.

**Framework baseline.** React Router v8 is the current stable major (v8.0.0 released 2026-06-17; latest stable v8.5.1 released 2026-10-27 — reactrouter.com/changelog, github.com/remix-run/react-router/releases). The app pins `^8.5.0` (`app/package.json:6-18`), i.e. the current stable release, not a pre/RC/canary channel.

**No experimental surface anywhere.**
- Zero `unstable_` / `experimental_` names, zero `future` flags: grep across `app/**` only matched `loading={...lazy}` on an `<img>` (`app/app/components/PokemonCards.tsx:18`) and a transitive lockfile entry.
- `app/react-router.config.ts:3-4` sets only `ssr: true` — the long-standing default mode. No RSC, no API-only mode (`ssr: "unstable_api-only"`), no `prerender`, no `unstable_customRouteDiscovery` (all v8.5 features the app explicitly *doesn't* use).
- Every imported API is long-stable, most since v7.0 in Nov 2024: `Layout` export, `Meta`/`Links`/`Scripts`/`ScrollRestoration`, `isRouteErrorResponse` (`app/app/root.tsx:1-30`); `data()` 404 throws (`app/app/lib/api.server.ts:60`, `app/app/routes/not-found.tsx:4`, `app/app/routes/type.tsx:23`); `Link`/`useNavigate`/`useLocation` (`app/app/routes/home.tsx:2`, `app/app/routes/pokemon.tsx:2`); generated `Route.LoaderArgs`/`Route.ComponentProps` types (`app/app/routes/home.tsx:4`, `app/app/routes/pokemon.tsx:1`); config helpers `RouteConfig`/`index`/`route` with a plain splat route for 404 (`app/app/routes.ts:1-9` — a stable, ordinary pattern, not a reserved convention).
- Custom Express server uses the stable `createRequestHandler` from `@react-router/express` (`app/server.mjs:3,13-16`) — the documented custom-server path, not the newer `unstable_*` server options.

**Recently-stable (not experimental) tooling.** `typescript@^7.0.2` (`app/package.json:26`) is the Go-native compiler that became the standard stable npm package on 2026-07-08 (devblogs.microsoft.com/typescript/announcing-typescript-7-0); it's used only for `typecheck`, so the missing JS programmatic API doesn't affect this app. React 19.3, Express 5, and Vite 8 are likewise stable tooling.

Risk assessment: this is about as conservative as a current-stable React Router app can be — nothing here is exposed to React Router's unstable-feature churn documented in the v8.5 changelog.
