**Highlights**

- **Framework APIs are fully current (v8, Oct 2026):** `Layout` export in root (`app/app/root.tsx:5`), typegen `Route.LoaderArgs`/`Route.ComponentProps`/`Route.ErrorBoundaryProps` (`app/app/routes/home.tsx:46,73`, `app/app/root.tsx:39`), `data()` for 404s (`app/app/lib/api.server.ts:37`), `@react-router/express` `createRequestHandler` with top-level `await import()` (`app/server.mjs:11-18`) — exactly the adapter pattern in the official integration templates, and it correctly targets the documented default `serverBuildPath` `build/server/index.js`. No `react-router-dom`, no `json()`, no deprecated `meta` `data` arg, no view-transition APIs (deprecated in 8.5.0 per the changelog), no `UNSAFE_`/`future.` flags.
- **Express 5 done right:** `app.all("/{*splat}", …)` (`app/server.mjs:15`) is the required path-to-regexp v8 wildcard syntax — many generated copies still break on Express 5's bare `"*"`.
- **Churn-resistant data layer:** all API access behind `app/app/lib/api.server.ts` with a single in-memory promise cache; loaders return pre-shaped view models, so components never touch raw PokeAPI shapes.
- **Platform-first touches:** `URLSearchParams`/`URL` for query state (`app/app/routes/home.tsx:15,47`), native `type="search"`/`<select>` controls whose GET form works without JS (`home.tsx:59-77`), React 19 native `<title>` hoisting instead of the `meta` export (`routes/move.tsx:39`), CSS custom properties + grid (`app.css:152-157`), top-level await, ESM-only.

**Dings:** `isbot` is declared but never imported (dead template leftover, `app/package.json:18`); `@react-router/node` is declared but only used transitively by the express adapter; the home/game pickers sync uncontrolled inputs to the URL via refs + `useEffect` + `document.activeElement` checks (`home.tsx:84-101`, `pokemon.tsx:209-214`) — clever and well-commented, but more fragile than controlled inputs driven from URL state; the `Move` response type is defined twice (`pokemon.tsx:44` vs `move.tsx:7`); API fetch has no `AbortSignal`/timeout (`api.server.ts:27`).
