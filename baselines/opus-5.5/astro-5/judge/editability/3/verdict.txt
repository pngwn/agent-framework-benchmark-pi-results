## Review

This is a small, cleanly factored Astro 7 app (current stable is 7.4.x; `app/package.json` pins `astro ^7.4.2`, `@astrojs/node ^11.1.9`, `output: 'server'` in `app/astro.config.mjs` — all current). Working through the five editability scenarios:

**1. Remove Abilities** — delete `app/src/pages/abilities/` and remove one self-contained `Section` block plus two frontmatter lines from the Pokémon page. The nav (`app/src/layouts/Layout.astro:21-22`) has no Abilities link; grep confirms no other references. No dead helpers left behind (`cardsForPokemon`, `humanize` etc. are shared with moves/types).

**2. Sprite fix (Deoxys)** — sprites render in exactly one place: `app/src/components/PokemonCard.astro:14`, backed by `spriteUrl()` at `app/src/lib/api.ts:75`. All four card lists route through `CardGrid.astro:14` → `PokemonCard`, so a URL-construction fix covers every list in one edit. If the fix is instead "which id/name the card carries", that lives in `cardsForPokemon` (`app/src/lib/pokedex.ts:123-139`) for moves/abilities/types, but the home page builds its own card data from `SpeciesEntry` implicitly (`app/src/pages/index.astro:29-30`) — so that class of fix is two places, not one.

**3. Sort cards by name** — the default dex order is baked in at `pokedex.ts:139` (covers three lists) and implicitly in `index.astro`'s species ordering, so a shared comparator needs two edits (plus per-page UI if it's a control).

**4. Items section shaped like Moves** — the data layer (`api.ts`, `resourcePath`, `englishName`, `display`, `MISSING`, `latestFlavorText`) and shell components (`Layout`, `Section`, `NotFound`) are fully reusable, but the detail-page scaffolding — fetch + 404 + effect-fallback + "count Pokémon" + CardGrid — is copy-pasted verbatim between `moves/[name].astro:18-33` and `abilities/[name].astro:9-17`. An items page would clone ~90 lines rather than parameterize. Also note Moves has no `/moves` index page, so `/items` has nothing in-repo to copy.

**5. Change API base URL / caching** — everything (base URL, freshness, cache size, sprite URL prefix, semaphore) lives in `app/src/lib/api.ts:4-8,75`. One file.

Other seams noted: the client-side "fetch HTML and swap a region" enhancement is duplicated between `index.astro:103-112` and `pokemon/[name].astro:226-235`; the API layer is `any`-typed so raw record shapes leak into page frontmatter (`pokemon/[name].astro:50-107` is a large block of raw shaping); the `typeLabels` map is rebuilt inline in two pages (`index.astro:26`, `types/[name].astro:19`) instead of using the existing `pokedex.ts:53` helper; `MovesTable.astro:14` keys a boolean column flag off the method name. Counterweights: `cardsForPokemon`'s `extra?: (ref) => Partial<Card>` callback is a genuinely well-designed variation point (the hidden-ability case at `abilities/[name].astro:17` needs no flag), and `scripts/sortable.ts` uses event delegation so swapped-in tables keep working without re-init.
