## Review — test quality

The app ships **zero tests of its own**. `app/package.json` has only `dev`/`build`/`start` scripts (no `test` script, no devDependencies), there is no Vitest/Playwright config under `app/`, and a grep across `app/src` for `describe(`, `test(`, `expect(`, `assert` finds nothing. The acceptance suite in `tests/` was given to the agent and is not its work, so it earns no credit here. Astro 7 (current stable, 7.4.2 — the app pins `^7.4.2`) has first-class, documented testing support: `getViteConfig()` from `astro/config` for unit tests of framework code like `src/lib/*.ts`, and Playwright for E2E — none of it is used.

Because there are no tests, `coverage_of_risk` and `regression_power` are 1 by the rubric, and `behaviour_not_implementation` is 1 ("or no tests"). `signal_to_noise` is 3 per the "no tests: 3" rule. The valuable part of this review is what the missing tests would let through, and there is a lot: this app is unusually rich in exactly the logic the rubric names — data transformation, filtering, pagination, URL state, caching, and client-side sorting.

The highest-risk untested logic:

- **`getSpeciesIndex()`** (`app/src/lib/pokedex.ts:55-108`) builds the species index by mapping type records' `pokemon` arrays onto species IDs and sorting by slot. Species absent from every type record silently keep `types: []` (`pokedex.ts:74`), which drops them from type filters and card badges without any error. A refactor of the slot-sort (`pokedex.ts:97`) would swap type badge order — a spec-visible regression — with nothing to catch it.
- **`compareMethods`** (`pokedex.ts:158-164`) implements the subtle "Level Up, Machine, Egg, Tutor, then alphabetically" ordering with an `Infinity`-sentinel trick; it looks right but is exactly the kind of comparator a unit test should pin.
- **Client-side sorting** (`app/src/scripts/sortable.ts:11-30`) has hand-rolled "missing values sort last in both directions" logic that checks emptiness *before* applying the direction sign, plus a `data-type`-driven numeric/text switch. A one-character change (applying the sign, or comparing numbers as strings) passes every acceptance assertion that only checks `aria-sort`.
- **URL/filter state** (`app/src/pages/index.astro:15-37`, client script `:76-144`): page clamping (`:24`), default-omission in `pageHref` (`:28-36`), the debounce + `latest` race counter in `render`, and the `popstate` restore (`:138-143`) — the last sets `select.value` from the query, which leaves a select with no option selected for an invalid value. Edge URLs (`?page=999`, `?type=notatype`, `q`+`type`+`generation` combined) have no guard.
- **The SWR cache** (`app/src/lib/api.ts:36-63`): 404s are cached as `null` for up to 60s (`:30-32`), so a Pokémon the API just added stays "Not found" until the entry expires; the `refreshing` flag reset-on-failure (`:51`) and FIFO eviction of possibly in-flight entries (`:63`) are classic concurrency-bug territory.
- **Alternate-form exclusion** (`pokedex.ts:35`, used at `:131`): `idFromUrl(ref.url) < 10000` is the only thing keeping Mega forms out of four different card lists, and `idFromUrl` (`api.ts:78`) returns `NaN` for malformed URLs, which silently compares false rather than erroring.
