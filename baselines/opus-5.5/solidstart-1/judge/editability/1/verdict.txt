## Review

**Architecture at a glance** (`app/src/`): routes → `lib/queries.ts` (`query` + `"use server"`) → `lib/server/model.ts` (view models) → `lib/server/pokeapi.ts` (fetch/cache). Components take view-model props from `lib/types.ts` and never fetch. That's a textbook SolidStart layering, and it's the main reason most edits are cheap.

**Scenario walkthroughs**

1. **Remove Abilities** — delete `routes/abilities/`, then `getAbility` (`lib/queries.ts:28-32`), `abilityData` (`lib/server/model.ts:296-304`), `AbilityData` (`lib/types.ts:68`), the Abilities section on the Pokémon page (`routes/pokemon/[name].tsx:115-125`) and `abilities` in `PokemonData`/`model.ts:195-197`. There's no nav link to remove. Tendrils: `Card.hidden` (`lib/types.ts:9`), the "Hidden ability" note in shared `PokemonCard.tsx:24`, and `.card__note` in `app.css:228` would be dead code. ~7 files, all mechanical deletes — a 3.
2. **Deoxys sprite fix** — every card's sprite is constructed from the species id in *two* parallel places: `cardsFor` (`model.ts:92`) for move/ability/type lists and the inline loop in `homeData` (`model.ts:126`) for home. Rendering is centralized through `CardList`/`PokemonCard`, so no per-page edits — but the model-side fix must land in both builders or you fix 3 of 4 lists. A 4 with a trap.
3. **Sort card lists by name** — all four card lists render via one component (`components/PokemonCard.tsx:33-45`), so a client-side sort could be added once in `CardList`; server-side ordering lives in `model.ts:93` and `model.ts:127` (again two sites), and home has URL-state plumbing to respect (`routes/index.tsx:10-38`). A 3.
4. **Items section like Moves** — `Section`, `PageTitle`, `CardList`, `display`, and all the API helpers (`api`, `apiOrNull`, `englishName`, `latestFlavorText`) stretch to it unchanged; you add 2 route files + one query + one model fn + one type. The page scaffold (`Show`/`NotFound` dance + facts `<dl>`) would be copied from `routes/moves/[name].tsx:20-37`. A 4.
5. **API base URL / caching** — `apiBase()`, `CACHE_TTL_MS`, `MAX_CONCURRENT`, the cache Map, and `spriteUrl` all live in `lib/server/pokeapi.ts` (lines 5-16, 29-55, 76); nothing else in the app knows the URL shape. A 5.
