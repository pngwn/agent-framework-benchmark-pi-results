**Stack check (as of 2026-10-30):**
- `@solidjs/start@2.1.0` (locked) — SolidStart **v2 went stable 2026-08-04** (github.com/solidjs/solid-start discussion #2281; release tag `@solidjs/start@2.0.0`). Stable, but only ~3 months old.
- `vite@8.3.5` — **Vite 8.0 stable 2026-03-12** (vite.dev/blog/announcing-vite8); it's the version SolidStart v2 *requires* (docs.solidjs.com/solid-start/v2, migration guide: `npm i ... vite@8`).
- `nitro@3.0.260903-beta` (locked) — **Nitro v3 is still on the beta channel; the first RC (`v3.0.261029-rc`) was published 2026-10-29**, i.e. yesterday, and ships a documented "Upgrading from Beta" breaking-changes guide (github.com/nitrojs/nitro/releases).
- All runtime code (`query`/`"use server"`, `createAsync`, `useParams`/`useSearchParams`, `A`/`Router`, `FileRoutes`, `HttpStatusCode`, `MetaProvider`, `Suspense`/`Show`/`For`, `StartServer`/`createHandler`, `StartClient`/`mount`) uses APIs that have been stable since SolidStart 1.x and are unchanged in v2 — verified against the imports at `app/src/lib/queries.ts:1`, `app/src/app.tsx:1-5`, `app/src/components/NotFound.tsx:1`, `app/src/entry-server.tsx:2`, `app/src/entry-client.tsx:2`.
- Zero `unstable_`/`experimental_` names or config flags (grep across `app/src`, `app/vite.config.ts`, `app/package.json`); the measured `experimental: []` matches.

Notably restrained choices worth crediting: the hand-rolled request-time in-memory cache + concurrency limiter at `app/src/lib/server/pokeapi.ts:9-49` instead of reaching for Nitro v3's `defineCachedHandler`/`cache` route rules — the very API the beta release notes flag as having **changed defaults** between betas ("Please review your caching configuration", release notes v3.0.260903-beta).
