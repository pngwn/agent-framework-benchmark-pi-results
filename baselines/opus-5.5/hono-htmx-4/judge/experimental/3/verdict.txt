## Review — experimentalness

I read all of `app/src/` (`index.tsx`, `api.ts`, `components.tsx`, `pages/home.tsx`, `pages/pokemon.tsx`, `pages/details.tsx`), `app/public/app.js`, `app/scripts/copy-assets.mjs`, the config files, and verified dependency statuses against current release notes.

### What the app actually uses

- **Hono v4 APIs**: `Hono`, `Context`, `c.html`, `c.header`, `c.redirect`, `app.notFound`, `app.onError`, `serveStatic` with `rewriteRequestPath`/`onFound` — all long-stable (`app/src/index.tsx:5-22`). Async hono/jsx server components (`app/src/pages/details.tsx:14`) are a documented stable hono/jsx feature, not experimental.
- **`hono/html` `raw`** for the doctype (`app/src/index.tsx:7,20`) and `hono/jsx` `FC`/`PropsWithChildren`/`Child` types (`app/src/components.tsx:1,8,14,22`) — all stable v4 surface.
- **htmx 2.0.11** (GA since 2024) with standard `hx-get/hx-trigger/hx-target/hx-swap/hx-sync` attributes and the `HX-Push-Url` response header — all stable htmx 2 surface (`app/src/pages/home.tsx:105-112`, `app/src/index.tsx:41`).
- **Node**: `import.meta.dirname`, `node:fs`, `node:path`, `node:module#createRequire` (`app/src/index.tsx:1`, `app/scripts/copy-assets.mjs:3-6`) — long-stable Node ≥20.11 features.
- **No experimental markers anywhere**: grep for `experimental|unstable|preview|canary|beta|rc\.` over `app/` returns nothing; the measured facts show `"experimental": []` and no config flags.

### Recency check (verified against sources)

- `hono@^4.13.14` is the **current stable** line as of 2026-10 (v4.13.14 released 25 Oct 2026; Hono v5 is only at `5.0.0-rc.1`, 10 Oct 2026 — the app wisely stays on stable v4). Source: honojs/hono releases / hono.dev migration guide.
- `@hono/node-server@^2.1.5` — v2 is a **stable** release (public API unchanged from v1; headline is a perf bump), shipped ~spring 2026. Source: honojs/node-server releases + npm.
- `typescript@^7.0.2` — TypeScript 7.0 (native Go port) went **stable on 2026-07-08**, ~3.5 months ago. Recently-stable, not experimental. Source: Microsoft devblog "Announcing TypeScript 7.0", npm.
- `htmx.org@^2.0.11`, `@types/node` — long-stable.

### Scoring

- **reach**: Nothing experimental at runtime; the only new-ish item is the TS 7 toolchain (stable for 3.5 months) in the build step, plus the node-server v2 adapter (stable, API-identical to v1). Between "only long-stable" (1) and "recently-stable in central places" (3) → **2**.
- **containment**: The one recently-stable piece (tsc) is confined to `package.json`'s `build` script; the adapter's surface is two imports plus `serve(...)` and `serveStatic(...)` in `app/src/index.tsx:2-3,18-24,90-94` — trivially swappable. → **5**.
- **justification**: No novelty for its own sake. TS 7 buys 8–12x faster builds; node-server v2 is simply the current stable adapter; htmx 2 is the only supported line. Nothing an older stable API would have served better. → **5**.

`count` of experimental/preview/RC/canary APIs: **0** (TS 7 and node-server v2 are counted as recently-stable, excluded per instructions).
