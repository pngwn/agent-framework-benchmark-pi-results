**The one preview-marked API.** `nodeServerAdapter` (`app/adapters/node-server/vite.config.ts:14`) is what Qwik's docs mark "This API is provided as an alpha preview… Do not use this API in a production environment" (https://qwik.dev/api/qwik-city-vite-node-server/). In practice it's the standard, officially generated path for every Node deployment (`qwik add node-server` emits this exact file, and Qwik's own e2e tests use the same import), but the docs status is what it is. Its `ssg: null` option is the public `ServerAdapterOptions.ssg` field and is required here by the SPEC's "don't prerender or embed API data at build time" rule.

**Version posture.** `@builder.io/qwik`/`qwik-city` are pinned exactly to `1.20.3` (`app/package.json:16-17`) — the latest stable patch, released 2026-10-25 — while Qwik v2 (`@qwik.dev/*`) is in RC. The app rightly stays on the stable v1 line and touches none of the RC APIs.
